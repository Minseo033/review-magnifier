화장품 5종, 중복 제거한 원문 28개: 쇼츠 8개·일반 영상 3개·블로그 17개·릴스 0개. 신규 제품의 영상 6개(에딧비 쇼츠2/일반1, 라로슈포제 일반1, 아누아 쇼츠2)와 블로그 13개를 더했다. 기존 퓌는 직접 구매 표시가 있는 9개만 유지하고, 표시를 확인하지 못한 채우 영상은 보류했다.

## 수집·검토 방법과 공개 범위

네이버 블로그는 naver-blog-research의 검색·본문 읽기로 전체 공개 텍스트를 읽고 구매 문장·제품명·조건과 상업적 관계 고지를 대조했다. YouTube는 공개 검색과 watch 페이지의 제목·설명·플랫폼 유료광고·길이·Shorts 형식·임베드 허용 메타데이터를 확인했다. 아누아 쇼츠는 설명이 비어 있어 공개 썸네일을 직접 열어 제품명 자막과 병 표기를 확인했다. 다른 제품의 후기나 수수료·협찬 고지를 찾은 자료를 포함하지 않았다. 로그인 제한·접근 통제를 우회하지 않았고 영상 파일·블로그 사진을 복제하지 않았다.

직접 구매 근거 문장과 위치, 정확한 제품/버전, 상충 고지 제외를 필수로 유지한다. 원문에 기재하지 않은 피부 타입·호수·기간을 추정하지 않는다. 후기 요약은 개인 경험이며 의학적 효능·보편적인 성능으로 바꾸지 않는다. 라로슈포제는 밤 B5+ 모델로 묶고 용량은 원문에 표기된 경우에만 표시한다. 대표 제품 사진은 100ml다. 아누아는 동일 캡슐100 모델로 묶으며 향 개선 시점이 명시되지 않으면 추정하지 않는다.

이전 수집 단계에서는 최초 프롬프트의 사람 승인 조건에 따라 비공개 후보로 보관했다. 후속 ‘찾고 사이트 적용·배포’ 요청에 따라 이번 묶음은 AI 원문 검토 방식임을 드러내고 공개한다. 원장의 `publicationAuthorization`에 사용자 요청·날짜·범위와 28개 ID·내용 해시를 고정했다. 사람이 원문을 시청했다고 기록하지 않았고 `--human-confirmed`를 사용하지 않았다. 이후 새 후보에 대한 무제한 자동 공개 허용이 아니다. 승인 범위를 벗어나거나 내용이 바뀌면 빌드가 거부한다.

한계: 영상 전체 장면·음성, 블로그 이미지 안의 글, 댓글·외부 링크의 추가 고지와 영수증 진위는 검증하지 않았다. 카드의 ‘근거 보기’와 기준 페이지에 AI 검토 방식과 확인/미확인 영역을 표시한다. 작성자의 내돈내산 자기표시와 구매 증빙 인증은 구별한다.

## 실제 화면

작은 메인 홈에서 제품 카드와 후기 영상 한 편을 함께 보여준다. 새 페이지 로드마다 직전 영상을 피해서 고르며 상품/저장함 탐색 중에는 유지한다. 형식별 전체 후기는 해당 제품 상세에 모은다. 상세는 사용자가 지정한 이전 홈의 제품 식별 카드 → 쇼츠 → 일반 영상 → 블로그 순서를 유지한다. 영상은 클릭 후 하나만 로드하며 자동재생하지 않고, 항상 원문 링크를 제공한다.

## 운영과 검증

운영 원장은 `data/discovery-registry.json`, 공개 추출은 `data/discovery.public.json`이다. 전체 HTML·본문과 검증 캐시는 `.local-data/rebuild/`에만 있고 Git과 공개 빌드에서 제외한다. 해시는 변경 감지 수단이며 원문 진위의 인증 수단이 아니다.

새 후보는 `npm run reviews -- add /절대경로/후보.json`으로 비공개 등록한다. `npm run reviews:queue`는 미승인 후보의 원문·구매 근거·검토 범위를 보여주는 로컬 목록을 만든다. 실제 운영자의 사람 검토 경로는 기존 `status ... approved ... --human-confirmed`이며 AI 검토 공개와 구분한다. 수집 후 삭제·변경·상충 고지를 발견하면 비활성화하고 재검토한다.

실행: `npm ci`, `npm run build`, `npm run preview` 후 http://127.0.0.1:4187/.
