# 에어팟 프로 2: 내돈내산 후기 전용 상세 개편

2026-11-12. 이번 개편 범위는 `#product/airpods` 상세페이지입니다. 다른 제품의 기존 상세·홈·비교 기능은 유지합니다. 다른 제품까지 내돈내산 전용 서비스로 전환했다고 주장하지 않습니다.

## 달라진 화면
- 제품 사진·이름은 작은 헤더로 축소합니다. 평점, 판매처 리뷰 수, 배송 분석, 긍정/부정 대시보드, 비교 패널을 에어팟 상세에서 제거합니다.
- 영상 / 텍스트 / 블로그를 전환하며 후기 자체와 작성자, 날짜, 모델, 원문 링크를 먼저 봅니다.
- 형식과 주제를 함께 필터링합니다. 빈 결과는 명시하고 전체로 초기화할 수 있습니다.
- 동영상은 재생 버튼을 눌러야 YouTube 개인정보 보호 강화 임베드가 로드됩니다. 자동재생하지 않습니다. 차단될 때에도 원본 링크가 남습니다.
- 텍스트 탭은 동일한 블로그 출처 2개의 짧은 원문 발췌입니다. 별도 작성자가 쓴 텍스트 후기 2개가 추가됐다는 뜻이 아닙니다. 전체 출처는 3개입니다.

## 엄격한 포함 기준
`data/self-funded-reviews.json`에 검토한 출처만 기록합니다. `selfPurchase: true`, `reviewed: true`, 명시적인 내돈내산 문구, 근거 위치, 확인 날짜가 모두 필요합니다. `commercialDisclosureFound: false`도 필수입니다. 쇼핑몰 별점, 구매 후기라는 명칭, 광고 표시가 없다는 이유만으로 내돈내산을 추정하지 않습니다.

작성자의 내돈내산 표시를 검토한 것이며, 영수증·결제 내역까지 검증한 인증은 아닙니다. 숨겨진 광고가 없다고 보증하지 않습니다. 화면에도 이 한계를 표시합니다.

확인한 제목·본문·영상 설명에서 협찬/제품 제공/제휴 수수료 표시를 발견하지 않았습니다. 글 주변의 플랫폼 광고까지 없다는 뜻은 아닙니다. 작성일은 게시물·YouTube 메타데이터 기준입니다. 일부 자료는 구형 Lightning 모델이므로 USB-C 후기로 표시하지 않습니다.

### 제외
- 기존 11번가 후기 3개: 내돈내산/광고 여부를 독립적으로 확인할 근거가 없어 새 상세에서 제외했습니다. 원본 저장 데이터는 훼손하지 않습니다.
- 김타치 USB-C 쇼츠: 내돈내산 표시가 확인되지 않아 제외했습니다.
- paperbound 블로그: 내돈내산을 표방하지만 쿠팡 파트너스 수수료 문구가 함께 있어 제외했습니다.
- 인스타 릴스·쇼츠는 근거를 통과한 출처를 확보하지 못해 빈 카드나 허위 링크를 넣지 않았습니다. 현재 영상은 일반 YouTube 영상 1개입니다.

## 유지보수
- 새 자료는 직접 원문 확인 후 JSON에 등록합니다. 형식별 숫자는 원문 출처 기준으로 계산됩니다.
- 홈에서 불확실한 기존 후기를 내돈내산으로 다시 이름 붙이지 않습니다.
- 배포 시 `npm run build`, `npm run check`, `npm run test:ui`, `npm run test:data`, `npm run verify:release`를 실행합니다.
- 이번 로컬 환경에서는 네이티브 esbuild/sharp 실행이 시스템 코드 서명 정책으로 차단되어, 동일 버전 esbuild-wasm으로 번들링했고 기존 변경 없는 브랜드 이미지를 유지했습니다. 공개 파일 준비/내보내기/검사 스크립트는 별도 실행했습니다. 프로젝트의 일반 빌드 명령은 변경하지 않았습니다.
