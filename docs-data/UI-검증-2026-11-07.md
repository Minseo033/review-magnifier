# 근거 중심 UI 수정 검증

## 변경
- 쇼핑 순위형 홈을 실제 원문·해석·미확인 정보 대조 예시로 전환
- 제품 카드: 실제 언급 수, 고정된 기본순, 모바일 제품명·사진 우선
- 상세: 기본 펼침 요약, 검토된 대표 발췌, 제품 사용/구매·배송 구분
- 일치하는 후기 ID의 기존 발췌만 노출하며 해당 주제 문장이 없을 수 있음을 표시
- 원문 미포함·광고 판별 미제공·검색 대상 20개 데모 경계 명시
- 중복 찜 링크와 안내 사이드바 제거, 기존 저장·비교 기능 유지

## 확인
- JS 테스트 16개 통과 (신규 렌더링·출처·이스케이프 테스트 12개)
- Python 테스트 22개 중 19개 통과, 로컬 원문 캐시 의존 3개 건너뜀
- 문법 검사 및 verify:release 통과
- 실제 브라우저 PC 1440px, 모바일 390px에서 홈·상세·카테고리·검색 결과 없음·검색 별칭·찜 유지·비교 확인
- 공개 제품 20개 / 후기 표본 160개 / 요약 58개 / 발췌 58개 유지

## 한계
- 광고/협찬 진위 판별 기능을 새로 구현했다고 주장하지 않음
- 실사용 성능, Lighthouse, 법적 적합성 검증 아님
- 이 작업 환경의 네이티브 esbuild/sharp 실행이 멈춰 동일 버전 esbuild-wasm 0.28.2로 번들 생성. 제품 데이터와 브랜드 이미지는 기존 검토된 정적 자산 유지. export.py/build-pages.py로 배포 산출물 갱신.
