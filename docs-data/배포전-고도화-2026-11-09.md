# 후기돋보기 배포 전 고도화 · 2026-11-09

## 대상과 근거

목적: 제품별 후기를 모아 읽고, 요약에서 실제 근거 발췌와 출처로 이동해 구매 전 판단을 돕는다.

대상: 검색·분류, 찜, 비교, 전체 상세 페이지, 출처 안내, 브라우저 저장, 공개 빌드·DB 이전.

확보한 근거: `source` 소스·확장 스크립트·수집 HTML, `automated` 로컬 원문 대조·jsdom 동작 테스트·Node/Python 테스트·배포 파일 검사. jsdom은 실제 브라우저 렌더링이 아니므로 화면 배치나 터치 성능을 검증했다고 표현하지 않는다.

## 검증과 남은 위험

결과: 화면·출판 정책 테스트 35개, 데이터 테스트 22개 통과. 공개 빌드 검사와 로컬 원문 160개 대조 통과. 로컬 HTTP에서 HTML과 스크립트·CSS·공개 제품 이미지 23개 파일의 내용 일치를 확인했다.

실행: `npm run build`, `npm run check`, `npm run test:ui`, `npm run test:data`, `npm run verify:release`, `npm run verify:sources`, `git diff --check`. 원문 대조는 제품 20개·후기 160개의 수집 주소, 후기 번호, 텍스트 해시, 발췌 위치를 확인한다. 검증에는 운영 DB 변경이나 외부 수집 요청을 사용하지 않는다.

미실행: 실제 브라우저 화면·모바일 터치·Lighthouse·axe. Codex 브라우저 연결이 `native pipe path unavailable`로 실패했고, Aside 브라우저는 연결 계정과 실행 프로필이 달라 접근하지 못했다. jsdom 자동 테스트는 이 한계를 대신하지 않는다. 배포 전 360/390/768/1280px에서 상세 요약·비교 가로 스크롤·고정 헤더·키보드 이동을 실제 브라우저로 확인해야 한다.

남은 자료 검토: 보류한 54개 제품의 실제 원문·사진·판매처 연결 근거를 확보한 후 공개 여부를 결정한다. 해시 일치 자체를 진위 인증으로 설명하지 않는다. 기존 공개 원문도 현재 판매 상태·링크 유효성을 재보장하지 않는다.

배포 상태: 로컬 수정과 `docs/` 배포 출력 생성까지 수행. GitHub 푸시·공개 배포는 수행하지 않았다. 검색 노출 설정은 기존 `preview` 상태이다.

## 회귀 확인

이전 근거: `009e04b`의 코드와 확장 스크립트, 기존 74개 후보 데이터. 이후 근거: 새 자동 테스트·공개 출력 검사·로컬 원문 대조.

수정 후 확인: 공개 대상 수치, 모든 공개 제품의 상세 렌더링, 검색 범위, 빈 상태 복구, 주제별 근거, 비교 상한·삭제 복구, 저장 제한, 사진/복사 실패, 잘못된 주소, 검색어 HTML 삽입 방지, 수집 데이터 변경 감지.

확인되지 않은 회귀: 실제 브라우저의 배치·스크롤·터치. 이를 완료된 것으로 간주하지 않는다.
