# 후기돋보기 공개 화면 점검 · 2026-11-07

서비스의 목적은 제품별 후기를 모아 읽고, 반복되는 경험과 그 근거를 확인하는 것이다. 기존 초록색 브랜드, 제품별 주소, 실제 후기 자료, 상위 3개/나머지 랜덤 규칙을 유지하며 화면과 탐색 동작을 보완했다.

## 수정 결과

| 우선순위 | 발견한 문제 | 반영한 내용 |
|---|---|---|
| P1 | 판매처 전체 리뷰 수와 실제 분석 표본 수를 혼동할 수 있음 | 상위 3개는 후기 내용·확인 표본 수를 먼저 배치. 일반 목록과 상세에서도 표본 수와 판매처 수치를 구분 |
| P1 | 비교 선택이 새로고침 때 사라짐 | 찜·비교·표시 방식 저장, 오래된 제품 번호와 중복 선택 검증, 브라우저별 저장 안내 |
| P1 | 앱 시작 실패 시 로딩 화면에 머묾 | 다시 불러오기·원문 링크를 제공하는 실패 안내. 사진 실패 시 제품명과 후기는 유지 |
| P2 | 약 1MB JS 안에 모든 제품 사진이 들어 있음 | 사진을 별도 정적 파일로 제공. 상위 사진 우선 로딩, 나머지 지연 로딩. JS 약 199KB로 81.2% 감소 |
| P2 | 카테고리 선택 때 검색어가 사라짐 | 검색어·분류 조합, 조건별 해제, 한글 브랜드·여러 단어 검색 |
| P2 | 모바일에서 후기 구간을 찾기 어려움 | 상세 상단에 요약/긍정·아쉬움/원문/출처 이동, 제품 주소 복사 |
| P2 | 작은 글자·조작 영역·비교 화면 가림 | 주요 버튼 44px, 검색 입력 16px, 카드 정렬과 비교 행 정렬, 비교 선택판 높이에 맞춘 여백 |
| P2 | 공유·저장·문의 안내 부족 | 사이트 공유 이미지·메타·아이콘·404 페이지, 브라우저 저장 안내, 승인받은 문의 이메일 연결 |

후기 요약과 원문 발췌를 구분하고, 긍정·아쉬움 언급 수 및 근거 후기 목록을 유지했다. 제품 사진은 후기의 대상을 알아보는 보조 정보로 사용한다. 판매·결제 동선은 추가하지 않았다.

## 확인한 범위

- **Ran:** 데이터 관련 Python 테스트 22개, 검색·주소·저장 선택·공개 자료 범위 Node 테스트 4개 통과.
- **Ran:** 빌드·문법·공개 산출물 검사 통과. 개인 DB와 원문 캐시가 없는 별도 임시 폴더에서도 빌드 성공.
- **Ran:** 공개 제품 20개, 확인 표본 160개, 요약 58개, 원문 발췌 58개 보존. 공개 폴더와 전달용 묶음에서 개인 DB·전체 원문·비공개 캐시·로컬 보고서 제외.
- **Ran / browser:** 데스크톱과 390px 모바일에서 첫 화면·검색·분류 조합·빈 결과·상세 복귀·구간 이동·링크 복사·찜·비교 제한과 새로고침·저장 안내·잘못된 제품 주소를 확인. 모바일에서 페이지 전체 가로 넘침 없음.
- **Ran / fault fixture:** 앱 파일을 누락시킨 별도 시험 페이지에서 재시도 안내 확인. 사진 파일 누락 시 대체 그림이 로드되고 20개 제품의 후기 탐색이 유지됨을 확인.
- **Ran / keyboard:** 검색 입력에서 다음 검색 버튼으로 이동 시 3px 초록 포커스 표시 확인.
- **Ran / source scan:** UI detector 0 errors / 2 warnings. 두 경고는 출처 표의 스크롤·고정 헤더를 찾지 못한 것으로, 실제 CSS와 브라우저에서 `overflow-x:auto`, `position:sticky`를 확인. 상태 문자열 검사도 통과했지만 이는 실제 동작을 전부 증명하는 검사는 아님.
- **Manual:** [29CM](https://www.29cm.co.kr/)와 [오늘의집](https://store.ohou.se/)을 브라우저에서 살펴보고 분류·정보 위계를 참고. 후기 탐색에 필요한 요소를 선택해 적용.
- **Skipped / 외부 확인 필요:** Lighthouse·axe 점수, 실제 사용자 부하, 화면낭독기 전 과정, 실기기 공유 미리보기, 지속 수집 운영과 정식 정책 검토.

초기 자바스크립트 크기 비교는 압축 전 파일 기준이다. 이미지 전송량까지 81.2% 줄었다거나 실제 체감 속도가 그만큼 빨라졌다는 의미는 아니다. 별도 사진 캐시와 지연 로딩을 활용할 수 있도록 바꾼 것이다.

## 데이터와 정식 운영의 한계

현재 공개 자료는 2026-11-05~07에 수집·검토한 **11번가 단일 출처의 표본**이다. 여러 플랫폼 전체 리뷰를 실시간으로 통합하는 서비스는 아직 아니다. 판매처 전체 리뷰 수, 판매처 표시 평점, 분석 표본 수를 각각 표시한다. 별점만으로 긍정·부정을 만들지 않으며 실구매·광고 여부를 인증하지 않는다.

원문 전체는 로컬 SQLite DB에 보관하며 GitHub Pages에는 검토한 공개 스냅샷을 배포한다. 정식 운영에는 이용 가능한 리뷰 공급 경로와 공개 범위, 공유 운영 DB와 서버, 갱신·검수·수정/삭제 요청 처리 절차를 갖춰야 한다. 문의 주소는 연결했으며 운영 주체와 실제 데이터 처리 범위에 맞춘 정식 정책 검토가 남아 있다.

시범 자료 상태에 맞춰 검색엔진 노출 제외를 유지한다. 제품별 `#product/...` 주소와 공유는 작동하지만, 외부 공유 미리보기는 사이트 공통 이미지다. 정식 검색 노출 시 제품별 크롤링 주소·메타·검색 등록을 별도로 검증해야 한다.
