# 영상·후기 함께 읽기 · 2026-11-13

사용자는 Instagram 이동 없이 영상과 본문을 함께 읽는 화면을 요청했고, 지금하는공구 상세를 참고로 제공했다. 참고 페이지 공개 HTML에서 video 요소와 자체 hit.09now.com 도메인의 미디어 주소를 확인했다. 그 사이트의 미디어 사용 권한 유무는 판단하지 않는다.

우리 에딧비 릴스의 공식 임베드는 video 요소 없이 ‘Instagram에서 보기’ 원문 링크로 재생을 넘겼다. 본문 포함 /embed/captioned/에서는 작성자와 원문 본문이 표시됨을 확인했다. 사용자는 작성자의 별도 영상 사용 허락을 받지 않았다고 답했다. 영상 파일·원문 본문 전체를 우리 공개 자료로 복제하지 않으며, 공식 게시물에서 본문을 읽고 원문으로 재생을 이어간다. 사이트 안에서 릴스를 직접 재생하는 기능을 완성했다고 주장하지 않는다.

구현은 왼쪽 영상/공식 게시물과 오른쪽 작성자·날짜·제목·후기 요약·짧은 원문 발췌(있는 경우)·작성자가 밝힌 조건·구매 근거·제품 연결·저장이다. 요약과 원문 본문을 구분한다. Shorts와 일반 YouTube 영상도 같은 읽기 화면을 쓰되 기존 공식 재생 방식을 유지한다. 저장 중 iframe을 유지하고, 닫기와 제품 이동에서 iframe·설명을 정리한다. 같은 제품으로 돌아가는 링크도 창을 닫는다.

자동 검증: UI·로직 66개 통과, 구문·빌드·공개 허용 파일·캐시 해시 대조 통과. 공개 제품 19개·원문50개와 승인 자료를 변경하지 않았다. 브라우저 1280×720에서 2열·창 높이 넘침 0, 390×844에서 1열·가로 넘침 0, 공식 게시물의 본문 표시를 확인했다. 실제 휴대폰 시각 검수와 영상 전체 재생 검증은 하지 않았다.
