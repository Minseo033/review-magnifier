## 포함 기준과 공개 방식

작성자의 명시적 내돈내산 문장·위치, 정확한 대상 모델, 확인한 영역에서 상충하는 광고·협찬·제공·제휴 고지가 없는 자료만 선정했다. 새 무드 글로이 틴트와 기존 잉크 무드 글로이 틴트, 자작나무 일반·톤업·무기자차, 네이밍 레이어드·매트·마스터, 제로이드 기본·리치·MD를 구분한다. 후기에서 밝히지 않은 피부·호수·기간을 추정하지 않는다.

새 자료는 사용자의 같은 방식 품목 확장·릴스 적용 요청에 따라 원문을 AI로 확인한 후 내용 해시별로 공개 범위를 고정했다. `publicationAuthorization.batches`에 이번 22개를 기록했고, 기존 28개와 구별한다. 사람 시청·영수증 검증으로 기록하지 않았다. 신규 후보를 무조건 공개하는 권한으로 확대하지 않는다.

YouTube는 공개 검색과 watch 페이지의 제목·설명·작성자·날짜·길이·Shorts·유료광고·임베드 메타데이터를 확인했다. 블로그는 소량 검색 후 본문 전체와 외부 링크 주소를 읽었다. 전체 본문·HTML은 비공개 캐시에서만 보관한다.

릴스는 Google 검색에서 후보를 찾고 Instagram 원문과 공개 메타데이터를 확인했다. 에딧비는 Safari의 로그인된 원문에서 작성자·본문·첫 화면의 실제 제품 병과 퍼가기 메뉴도 확인했다. 공개 /embed/ 문서도 두 원문에서 접근 가능했다. 공식 Instagram 임베드 프레임을 사용자가 누를 때만 하나 열며, 원문 이동을 항상 제공한다. 별도 Instagram API 키나 계정 생성·로그인 자동화는 추가하지 않았다.

릴스 작성자의 사진·영상 파일을 복제하지 않는다. 미리보기는 ‘제품 사진’이라고 구별한 공식 제품 사진이며 영상 썸네일로 가장하지 않는다. 아누아 릴스 작성일은 공개 원문에 없어서 미표기다. 유료 파트너십 메타데이터 전체·영상 음성/장면·댓글과 외부 링크의 추가 고지·구매 증빙은 확인하지 못했으며 후기별 범위에 표시한다.

## 보류·제외

리워드 링크가 있는 에스네이처 블로그, 수수료 고지가 있는 VT·토리든 영상, 유료광고 메타데이터가 있는 롬앤 자료를 제외했다. 라운드랩 톤업 글은 기본형과 다른 제품이고 제휴형 링크도 있어 보류했다. 토리든 시나모롤 릴스는 구매 근거는 확인했지만 리뉴얼 버전 일치가 해결되지 않아 보류했다. 크리니크 공식 이미지 접근 제한(429)에서는 추가 요청을 중단했다. 개별 기록은 `data/discovery-findings.json`에 있다.

## 화면·운영

작은 제품 선택 홈과 기존 제품 상세의 형식별 구성은 유지한다. 19개 제품을 베이스/색조/스킨케어·선케어/클렌징으로 탐색한다. 홈의 한 편은 쇼츠와 릴스 중 새 로드 때 고르고, 탐색 중에는 유지한다. 릴스는 상세 형식 탭과 저장함에서도 원문·근거·날짜를 확인한다.

제품 수가 늘면서 화면 코드와 공개 자료를 `discovery.bundle.js`와 `discovery.data.js`로 분리했다. 데이터가 먼저 로드되도록 defer 순서를 고정하고 각각 해시로 갱신한다. 렌더러는 약32KB, 공개 자료는 약121KB다. API 서버·새 DB를 만들지 않았으며 raw/HTML/미승인 후보는 공개 파일에서 제외한다.

검증: UI·로직64개와 데이터22개, 총86개 통과. 구문·빌드·공개 파일 허용 목록·이미지 일치·중복·버전·승인 해시와 비공개 원문 캐시50개를 대조했다. 실제 모바일 기기 시각 검수와 영상 전체 시청·구매 증빙 검증은 하지 않았다. 잠금 해제 후 Safari에서 확장된 홈과 분류, 에딧비 상세의 릴스 필터와 공식 Instagram 임베드 표시를 확인했다. 임베드의 작성자·첫 화면·Instagram 원문 링크·닫기 동작을 확인했으며, 재생은 Instagram에서 보기로 이어질 수 있다. 전체 영상 재생을 검증한 것은 아니다.
