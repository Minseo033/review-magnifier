# 후기 콘텐츠 탐색 서비스 재구성 · 2026-11-12

## 목적과 변경 내용

제품 검색 → 제품 선택 → 플랫폼별 사용 경험 탐색 → 실제 원문 확인으로 핵심 흐름을 바꿨다. 홈·검색·제품 상세·저장함·공개 기준·저장 안내를 새 HTML/CSS/JavaScript로 구현했다. 그린 계열 쇼핑 목록, 사양·별점·배송 비교, 3D 장식과 에어팟 기본 화면은 새 빌드에서 제외했다. 기존 원본 코드, 제품 사진, 분석 자료와 비공개 SQLite는 보존했다. 이전 진입 HTML과 설명은 `legacy/`에 있다.

새 공개 운영 원장은 `data/discovery-registry.json`이다. 소수의 검토 대상 링크를 관리하는 데 서버 DB를 추가하지 않았다. 기존 SQLite는 이전 판매처 자료의 보관·수집 용도로 남겼으며 새 앱이 자동 읽지 않는다. 승인된 원장 → `data/discovery.public.json` → 정적 번들 → `docs/` 순서로 배포된다. 사용자의 제품·후기 저장 목록은 브라우저의 v5 저장 공간에만 있다.

## 포함·제외 정책과 검토 한계

사용자 후속 지시에 따라 직접 구매 문구는 필수 조건이 아니다. 제품이 일치하고 확인 영역에서 광고·협찬·제품 제공·제휴 고지가 발견되지 않은 자료를 포함할 수 있다. 카드의 ‘작성자 내돈내산 표기’와 ‘광고 표기 미발견’을 구분하고 확인한 영역과 확인하지 못한 영역을 펼쳐 보여준다.

초기 공개 목록의 검토자는 **Codex이며 사람의 수동 승인으로 기록하지 않았다.** 블로그 제목과 본문 텍스트, 영상 제목·설명·유료광고 메타데이터를 대조했다. 영상 장면·음성·블로그 이미지에만 있는 고지는 검토하지 못했다. 사람이 모든 영상을 시청한 목록이나 영수증 검증 자료가 아니다. 이 한계를 사이트의 기준 페이지에도 표시한다. 정식 운영 전 사람이 영상·이미지 고지를 검토하는 작업은 남아 있다.

피부 타입·톤·호수·시간 경과는 원문에 있는 값과 짧은 근거 및 위치를 저장한다. 없으면 null로 두며 필터에서 추정값을 만들지 않는다. 요약은 ‘편집 요약’, 인용은 ‘원문 발췌’로 표시한다. 조명·파우더 사용 등 개인의 조건을 제품 전체의 성능으로 일반화하지 않는다.

전체 본문과 HTML은 `.local-data/rebuild/`의 비공개 캐시에만 보관한다. 공개 저장소에는 메타데이터·짧은 인용·편집 요약을 저장한다. 승인 내용의 해시는 변경 감지용이며 진위를 인증하지 않는다.

## 검증 범위

검토 원장·출력 검증은 `npm run verify:release`, 비공개 원문 대조는 `npm run verify:sources`로 재현한다. 후자는 해당 캐시가 없는 새 체크아웃에서는 실행되지 않으며 일반 빌드는 캐시를 요구하지 않는다.

화면 동작은 jsdom에서 신규 서비스와 보존한 이전 코드의 회귀 테스트를 실행한다. 신규 테스트는 별칭 검색, 전역 날짜 순서, 필터 조합·빈 상태, 저장·저장 제한, 공유 실패, 단일 iframe·원문 복구, 본문 건너뛰기, 운영 CLI와 승인 실패 시 비공개를 확인한다. 모바일 폭 390 설정의 필터 상태·이벤트도 포함한다. jsdom에는 배치 엔진이 없어 실제 너비·줄바꿈·스크롤·터치·영상 재생은 검증하지 못한다.

이 작업 환경에서 앱 내 브라우저는 연결 경로 오류로 접근하지 못했고, 대체 연결도 계정 불일치로 작동하지 않았다. 따라서 실제 데스크톱/모바일 스크린샷, 시각 검수, 영상 재생 성공이나 접근성 인증을 완료했다고 주장하지 않는다. CSS는 모바일 분기·44px 조작 영역·초점·대비를 보강했으나 실제 기기 확인은 남는다.

기존 GitHub Pages 배포 경로를 유지한다. CI에서 구문 검사·빌드·UI/데이터 테스트·공개 파일 검증이 통과한 경우에만 `docs/`를 배포한다. 실패 시 이전 배포를 유지한다. 되돌리기는 이전 커밋의 공개 파일을 복원하는 후속 커밋으로 수행한다.


## 후속 사용자 수정: 홈의 크기와 상세 구성

메인 홈의 데스크톱 최대 너비를 1080px로 맞추고 제목을 32px에서 26px, 제품명을 20px에서 16px로 줄였다. 제품 사진 영역은 16:10에서 16:7로 낮추고 간격과 패딩을 줄였다. 홈페이지에서 중복되던 상단 검색은 숨기고 본문 검색을 사용한다. 모바일의 입력 글자 크기와 조작 영역은 유지했다.

상세는 5ccd41a의 이전 홈 구성을 사용한다. 제품 식별 카드 뒤에 쇼츠 4개, 일반 영상 2개, 블로그 4개가 각각 전체 너비 섹션으로 이어진다. 왼쪽 필터와 형식이 섞인 피드를 제거했다. 조건 필터는 기본 접힘 상태의 상단 영역으로 옮겼다. 날짜 정렬은 각 형식 안에 적용하며 화면에서 ‘형식별 정렬’로 표시한다.

Ran: UI 테스트 57개, 공개 빌드 검증. Safari에서 1920×984 캡처를 통해 메인 홈과 제품 상세, 제품 클릭 후 상세 이동을 확인했다. 4190 포트가 WebKit의 제한 포트로 차단되는 문제를 확인해 기존 미리보기 명령의 4187 포트에서 새 빌드를 확인했다. 이전의 브라우저 접근 실패와 별개로 이번 데스크톱 검수는 실행됐다. 실제 모바일 기기의 시각 검수는 남아 있다.
